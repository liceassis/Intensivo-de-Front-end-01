Diferença entre UX e UI

psychology

UX - User Experience

UX está relacionado à experiência do usuário durante a utilização de um site ou sistema.

Envolve facilidade de uso, organização, navegação, acessibilidade e satisfação do usuário.

palette

UI - User Interface

UI está relacionado à aparência e aos elementos visuais de uma interface.

Envolve cores, tipografia, botões, espaçamento, ícones e organização visual.

Análise de um site famoso

YouTube

O YouTube apresenta uma interface organizada e intuitiva, facilitando o acesso aos vídeos, canais e ferramentas de interação da plataforma.

Aspectos de UI

  • Interface visual organizada.
  • Uso de miniaturas para identificar os vídeos.
  • Menus e botões facilmente identificáveis.
  • Boa organização dos conteúdos na tela.

Aspectos de UX

  • Navegação simples entre diferentes conteúdos.
  • Facilidade para encontrar vídeos por meio da busca.
  • Recomendações personalizadas de conteúdo.
  • Experiência de uso adaptada a diferentes dispositivos.
